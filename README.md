# MML VU-Deck — Dual Display Web Flasher & Controller Guide

Welcome to **MML VU-Deck Dual Display**!

To flash your device or control it in real-time, open [MML VU Deck Official Webcontroller](https://micromakerlabsfiles-git.github.io/MML-VU-Deck/) in any Web Serial compatible browser (Google Chrome, Microsoft Edge, or Opera).

---

## 🎛️ Web Controller Features

- Select between all 19 visualizer themes.
- Toggle between **Mono Mode** (mirrored single channel) and **Stereo Mode** (independent dual channels).
- Select sensor type: Normal Sound Sensor (LM393), MAX4466, or MAX9814 AGC.
- Adjust individual sensor sensitivity gain (1x to 64x) and physics response models.
- Rotate display 180 degrees, invert display colors, or swap stereo channels.
